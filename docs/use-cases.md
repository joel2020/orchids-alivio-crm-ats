# Use Cases

## 1) Independent recruiter: lightweight ATS + outreach
- Create candidate and job records from intake calls.
- Track every submission and interview milestone.
- Run follow-up automations for inactive submissions.

## 2) Boutique staffing firm: standardized client delivery
- Use shared status taxonomy across recruiters.
- Centralize candidate notes and activity history.
- Trigger handoff tasks between sourcing and delivery teams.

## 3) AI-assisted recruiting operator
- Use prompt templates to draft candidate summaries.
- Generate first-pass outreach with human approval.
- Route signals to n8n for reminders and SLA monitoring.

## 4) Healthcare recruiting adaptation
- Add compliance and credential fields in candidate profiles.
- Introduce license state and expiration checks.
- Add specialty-specific qualification screening prompts.

## 5) Generalist agency adaptation
- Keep core entities unchanged.
- Add custom pipeline stages by vertical (tech, sales, operations).
- Extend webhook adapters for your sourcing channels.
